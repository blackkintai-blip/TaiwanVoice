# 実機確認チェックリスト

自動テストでは確認できない項目。両端末で一度ずつ確認してください。

## iPhone

- [ ] 公開URLをSafariで開き、共有メニューから「ホーム画面に追加」できる
- [ ] 一覧画面でカードをタップすると台湾華語（zh-TW）の声で発音される（大陸の声ではないことを確認）
- [ ] 発音が鳴らない場合、設定 > アクセシビリティ > 読み上げコンテンツ > 声 に「中国語（台湾）」が表示されるか確認する
- [ ] 機内モードにしてアプリを開き直しても起動し、カード一覧が表示される
- [ ] 「聞く」画面で自動連続再生（中文→例文→次のカード）が途中で止まらない
- [ ] 長い例文（10文字以上）が途中で切れずに最後まで読み上げられる

## Android

- [ ] 公開URLをChromeで開き、メニューから「ホーム画面に追加」できる
- [ ] 一覧画面でカードをタップすると台湾華語（zh-TW）の声で発音される（大陸の声ではないことを確認）
- [ ] 発音が鳴らない場合、設定 > 一般管理 > 言語とキーボード > テキスト読み上げの出力 でエンジンの言語データに「中国語（台湾）」を追加する
- [ ] 機内モードにしてアプリを開き直しても起動し、カード一覧が表示される
- [ ] 「聞く」画面で自動連続再生(中文→例文→次のカード)が途中で止まらない
- [ ] 長い例文（10文字以上）が途中で切れずに最後まで読み上げられる

## 両端末共通

- [ ] 設定画面でバックアップを書き出し、もう一方の端末で読み込むと、両方のカードが残る（マージされる）
- [ ] 注音が明らかに間違っているカードを手で修正し、「辞書を再適用」を押しても修正内容が消えない
